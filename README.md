# Three-Tier Enterprise Network Topology

## Overview

This project demonstrates a Cisco Packet Tracer implementation of a Three-Tier Enterprise Network Architecture.

The design includes:

- Core Layer
- Distribution Layer
- Access Layer

## Features

- VLAN Segmentation
- Inter-VLAN Routing
- DHCP Configuration
- RIP Routing Protocol
- Server Services
- Enterprise Hierarchical Design
